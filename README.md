# Antaral Studio

Portfolio website for **Antaral Studio**, led by Principal Architect Ar. Monish Machhi.

The site presents selected architecture and interior projects, studio credentials, services, and a prominent inquiry path. Its visual system combines an animated wordmark, editorial project layouts, and an image-led project carousel.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` (or the port shown in the terminal).

## Build

```bash
npm run build
```

## Updating the portfolio

- Main content and project entries: `app/page.tsx`
- Styling and animations: `app/globals.css`
- Browser and social metadata: `app/layout.tsx`
- Project images and social preview: `public/`

Replace the placeholder project image URLs and credibility numbers in `app/page.tsx` as final material becomes available.
